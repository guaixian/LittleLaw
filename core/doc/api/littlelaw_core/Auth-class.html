Auth

Auth class

应用层鉴权:共享会话令牌(配对时经 PIN 验证的通道协商)。

传输层已有 TLS + 服务端证书指纹 pinning,令牌用于服务端反向确认 调用方身份(grpc-dart 客户端无法出示客户端证书,故用令牌替代 mTLS)。
