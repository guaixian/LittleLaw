FileVault

FileVault class

文件落盘加密:收到的图片/视频/语音/文件以密文形式存放在收件目录, 防止文件被直接拷走(共享目录、网盘同步、备份泄露等场景)。

格式 LLF1: "LLF1"(4B) | 1B 版本 | 12B 文件 nonce | 分块: 4B 长度 LE | 密文 | 16B GCM tag,块大小 1 MiB, 每块 IV = nonce(8B) || 块序号(4B LE)。

主密钥:<dataDir>/vault.key,32 字节随机,首用生成。 注意:这是"文件级加密",主密钥与密文同目录存放,防的是文件本体外流, 全盘保护仍应依赖 BitLocker/FileVault 等系统级加密(README 有说明)。
