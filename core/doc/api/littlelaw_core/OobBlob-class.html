OobBlob

OobBlob class

OOB(带外)引导包:通过二维码 / NFC / 复制粘贴等带外通道交换, 用于远程配对与 WebRTC 信令。物理/人工通道天然抗中间人, 包内证书指纹成为之后所有连接的信任锚。

编码格式: LLB3 = base45(lzma(JSON)) —— 当前默认,LZMA 高压缩 + QR 字母数字 模式(97% 编码效率),同等内容二维码面积最小; LLB2 = base64url(gzip(JSON)) —— 兼容解码; LLB1 = base64url(JSON) —— 兼容解码。
