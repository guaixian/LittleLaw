Identity

Identity class

设备身份:首次启动生成,终身不变。

组成:

  • deviceId: UUID v4
  • deviceName: 用户可见名称(可改)
  • EC P-256 密钥对 + 自签 X.509 证书(TLS 传输凭证)
  • 证书指纹 = SHA-256(cert DER) hex,配对与连接时的信任锚
